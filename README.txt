# Task 05 - Weather App
## Nikshith Jampala

A responsive weather web application built with HTML, CSS and JavaScript.

### Features
- Search weather by city name
- Use current device location
- Current temperature
- Feels-like temperature
- Weather condition
- Humidity
- Wind speed
- Atmospheric pressure
- Cloud cover
- Responsive design for desktop and mobile
- Loading and error messages
- No API key required

### Technologies
- HTML5
- CSS3
- JavaScript
- Fetch API
- Open-Meteo Geocoding API
- Open-Meteo Weather API

### Run in VS Code
1. Open this folder in VS Code.
2. Open `index.html`.
3. Right-click the file.
4. Select **Open with Live Server**.
5. Search for a city such as Hyderabad, Mumbai, Delhi or London.

### Important
Internet access is required because the app gets live weather data from Open-Meteo.

If browser geolocation is used, allow location permission when the browser asks.
